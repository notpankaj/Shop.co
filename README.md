# SHOP.CO Backend

An Ecommerce App in MERN Stack

### POSTMAN FILE inside /postman ☺️

## Run Locally

Clone the project

```bash
  git clone https://github.com/notpankaj/Shop.co.git
```

Go to the project directory

```bash
  cd Shop.co
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
